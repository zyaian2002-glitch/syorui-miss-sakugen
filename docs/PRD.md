# 書類ミス削減 PRD（v1.0 候補・承認待ち）

> ステータス：**Haru の最終承認待ち**。承認されるまで実装しない。
> 最終更新：2026-11-01

## 1. デザイン戦略（合意済み）

### ターゲットと本質的欲望
- **対象：** Haru 本人（自分で作成する Excel / Word の書類）
- **本質的欲望：**「ミスを出さない」という**安心感**
  - 「確認せずに出す人」と思われたくない
  - 修正や訂正の手間をなくしたい

### ゴールライン
- 書類：月に15〜20枚（うち8〜10枚は同じ様式、残りは毎回違う様式）
- 実際に起きたミス：①年号が古いまま（令和7年など） ②Excel で右端の列が印刷で切れる ③漢字の誤変換・誤字脱字
- **価値になる境界線：** ①②は印刷する前に機械が確実に止める。③はAIに確実に見せる流れが毎回できている

### デザインプリンシプル（優先順位）
1. **見逃しゼロ ＞ 誤検知の少なさ**
2. **思い出さなくても動く ＞ 自分で起動する**
3. **他の職員を混乱させない**
4. 正直さ：確実に見つけられるもの（①②）と、確率でしか見つけられないもの（③）を分けて表示する

## 2. 環境
- Microsoft Office Professional Plus 2016（バージョン 2508、クイック実行）／ Windows
- **PC は複数の職員が同じ Windows アカウントで使っている** → ログイン情報では本人を判別できない
- マクロは使える。個人用マクロブック（PERSONAL.XLSB）と Word の Normal.dotm を使う予定（手順書付きで導入）
- AI：Haru 個人契約の Claude（チャット画面）。API は使わない

## 3. v1 の範囲（作るもの）

### A. 印刷前の自動チェック（Excel・Word 共通の動き）
- 印刷ボタンを押すと自動で実行される
- 問題がなければ何も表示せずに印刷する
- 問題があれば一覧を表示して、「戻って直す」か「それでも印刷する」かを選ばせる
- **ON/OFF の切り替えスイッチ（普段は OFF）**
  - Excel と Word のタブに「書類チェック」を追加し、そこで ON にする（Excel と Word は別々に ON にする）
  - 画面下のステータスバーに「書類チェック：ON / OFF」を常に表示する
  - Excel / Word を閉じると OFF に戻る → 他の職員の画面には何も出ない

### B. 日付・年号チェック（Excel・Word）
- 今年（令和8年 / 2026年）以外の年号・年をすべて指摘する
- 年度をまたぐ時期（1〜3月）は、前年も「要確認」として指摘する（見逃しゼロの方針に合わせる）
- 和暦と西暦の混在、日付と曜日のずれ（例：「11月1日（月）」）を指摘する
- 「令和○年」のような文字の日付と、Excel の日付データの両方を対象にする

### C. 印刷の見切れチェック（Excel）
- 印刷範囲・ページの外にはみ出したデータがある
- 横方向に2ページ以上に分かれる（右端の列が切れる典型）
- ページ数が多い、または1列・1行だけが別ページになる

### D. 漢字チェック用のコピー（Excel・Word）
- ボタン1つで、書類の本文と「誤字・誤変換・脱字を指摘して」という指示文をまとめてクリップボードにコピーする
- Haru がそれを Claude に貼り付ける
- ON のときだけ、印刷前に「漢字チェックは済みましたか？」を**毎回**確認する（貼り忘れ対策）

## 4. 対象外
- 他の職員が提出した紙書類のチェック → 次の課題
- API による AI の自動呼び出し（案B）→ 案Aが面倒になったら会社に確認して検討する
- Word の文章の印刷見切れ（Word は余白の外に文字が出にくいため、v1 では扱わない）

## 5. 文脈設計（UXの4ステージ）
- **知る：** 自分用なので不要。存在を思い出さなくても印刷時に勝手に動く
- **アクセスする：** 職場の共有PCで、書類を作り終えて印刷ボタンを押した瞬間
- **使う：** 問題がなければ何も起きない。問題があれば赤い一覧が出る。漢字はコピーして Claude に貼り付ける
- **結果（残る感情）：**「これで出して大丈夫」という安心感

## 7. 受け入れ基準（完成の判定）
